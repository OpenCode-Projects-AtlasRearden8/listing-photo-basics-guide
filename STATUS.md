# STATUS.md — Listing Photo Basics

Last updated: 2026-11-05

## What was built

A complete small-business manual on **resale listing photography** (eBay / Amazon / Etsy / KDP), delivered two ways:

1. **`docs/`** — the manual as 11 Markdown pages, written to be read in numbered order:
   - `index.md` — intro, who it's for, how to use
   - `01-corner-lab.md` — the corner photo lab on three budgets ($0 / ~$25 / ~$75)
   - `02-light.md` — window light, bounce, diffusion without a rig
   - `03-condition.md` — honest flaw shots that prevent "not as described" disputes
   - `04-backgrounds.md` — backdrops and the ruler/coin/tape scale habit
   - `05-cleaning.md` — fair before/after cleaning pairs
   - `06-editing.md` — phone editing that fixes the camera's lies, not the item's facts
   - `07-marketplaces.md` — per-platform size habits for eBay, Amazon, Etsy, KDP covers
   - `08-shot-lists.md` — shot-list cards for nine item categories
   - `09-editing-checklist.md` — one-page pre-upload checklist + low-energy batch plan
   - `10-glossary.md` — plain-English photography and marketplace vocabulary
2. **`site/`** — a static HTML version of the same manual, generated by `build.py` (pure Python: standard library + the `markdown` package; no network, no CDNs, no external fonts).

Supporting files: `build.py`, `README.md`, `LICENSE` (MIT), `.gitignore`.

## How to run

```bash
python3 -m pip install markdown   # if not already present
python3 build.py
```

Then open `site/index.html` in any browser. Everything is local-first; the site works offline (plain HTML + one local stylesheet, no web fonts).

Running `build.py` regenerates `site/` from scratch (`docs/*.md` are the source of truth; `site/` is build output that is also committed so the site is readable without Python).

## Known gaps / future work

- **Plain Markdown essay style:** the shot-list "cards" are Markdown tables styled as tables, not standalone card tiles; a card-grid layout would be a nice future upgrade.
- **No page-anchor ids:** headings don't carry deep-link anchors yet (adding heading ids is a small build.py change).
- **No tests directory:** build verification is done by inline checks documented above; a `tests/` folder with the same assertions as a runnable script would make this a one-command check.
- **Etsy "lifestyle" guidance and Amazon category-specific style guides** (clothing, jewelry, shoes each add nuance) are summarized rather than exhaustive — category style guides were spot-checked from public style-guide PDFs but not catalogued page-by-page.
- **eBay/Amazon file-size ceilings** are summarized conservatively; platforms occasionally revise them, so the pages link nothing stale — the manual tells readers the platform help page always wins.
- **No images in `docs/`:** the manual is text-only by design (no sample photos shipped), so each shot-list card reads as a checklist rather than an illustrated plate.
