Editing Checklist

Run this before every upload. It’s deliberately short enough to keep in the corner of your screen. If you use only one page of this manual forever, use this one.

The 6-point pre-upload checklist

  • ☐ Shots present. Overview, sides, details, flaws, scale — every slot on your category’s shot-list card filled or consciously skipped.
  • ☐ In focus. Zoom to 100% on the phone: edges crisp, not painterly. Detail shots need actually-sharp close-ups.
  • ☐ Exposure true. Whites read as white, blacks not like gray, dark items not like voids. Compare to the item in the room.
  • ☐ Color true. Cream isn’t yellow (wrong white balance); blues are blue. If you edited anything, check the color shift (see Phone editing without fakery).
  • ☐ Flaws visible, not explained away. Every flaw: straight-on, close-up, with a size reference (fingertip, coin, ruler). If a flaw can be found in slot 14 without a magnifying glass, it’s disclosed (see Honest condition shots).
  • ☐ Scale is proven. At least one photo with ruler/coin/tape/hand, in the same plane as the item.

The 3-point ethics check

  • ☐ Nothing erased. No scratch, smudge, watermark mistake, or background clutter with information value cropped/erased where a buyer would care.
  • ☐ Color untouched. No filter that shifted any real color (that’s “buyers choose by color”).
  • ☐ Description matches photos. The words say the same thing the photos show. If you cleaned something, the disclosed before/after pair isn’t contradictory (see Before/after cleaning shots).

The 2-point delivery check

  • ☐ Exported per-platform sizes. eBay 1,600+; Etsy 2,000–3,000; Amazon 1,600–2,000 with a white main image; KDP ebook covers designed at 2,560 × 1,600. Full detail: Per-marketplace size habits.
  • ☐ Originals kept. Before-editing versions stored somewhere predictable — a folder named for the item. Your receipt if a dispute ever comes.

Some trouble habits worth dropping

Habit Swap to
Shooting portraits-ish vertical, when slot 1 is landscape Film the platform orientation in mind (eBay: 1:1 or 16:9; Etsy: square or 4:3)
“I’ll crop later” mentality Crop and straighten at capture; the grid overlay helps
Repeat albums named IMG_3481.jpg Rename by item/slot (sku-03-flaw.jpg) before the pile gets deep
One take, no backup Two takes for anything irreplaceable (breakable, borrowed, one-of-a-kind)

For low-energy days

Batch strategy for the times when time itself is short (ADHD-friendly by design):

  1. One category per session. All hats, or all mugs — never mix hats and mugs in a photo run, since the light setup is per category.
  2. Focus on a good overview and the flaw shots first for each item, even if the details run short of a full card. A listing with the essentials beats a half-finished listing.
  3. The minimum viable listing photo set is 6: overview (1), one opposite side (1), two detail/flaw shots (2), one in-context/size shot (1), one scale shot with the flaw in it (1).
  4. Stop when the light changes. Perfect is impossible; unfinished-in-good-light is worse than basic-in-good-light. Treat Light without a rig as your schedule-planner, not as a perfection deadline.
